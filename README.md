\*---使い方---\*



start.batをダブルクリックで起動。



.envで設定をいじれます。



ファイル「bat」の中にはLLMやTTSサーバ起動のための.batファイルが入ってます。~~そこでポート番号やGPUを使用するかを設定できます。~~

詳しくは、それぞれ中に入っている MANUAL.txt を参照してください。

ただ、あまり使わないので無視しちゃってもいいかも。



~~ollamaの場合は.envで、Kobold.cppの場合は koboldcpp/models/main の中に使いたいLLMを入れて.batをいじることで、LLM自体を変えることもできます。~~



記憶をリセットしたい場合はDBファイルを削除してください。もしもの時のためにバックアップを取っておいた方がいいと思います。







\*---必要条件---\*



最低でもVRAM8GB、RAM32GBくらいを想定してます。



初期条件で起動して無理そうであれば、LLMを変えたり、GPUの使用を抑える設定にしてみてください。



例

&#x20; LLMのサイズを下げる

&#x20; TTSをCPUモードで起動する(.batをいじる)

&#x20; STTをmoonshineにする(CPU使用なのでだいぶ軽いです)





本当に最軽量にすればRAM16GBとかでも動くかも。
